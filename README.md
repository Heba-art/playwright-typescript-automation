## Project Goals

- Build a professional Playwright framework from the ground up.
- Design formal test cases before automating them.
- Use Page Object Model, fixtures, reusable utilities, and test-data management.
- Cover positive, negative, end-to-end, API, hybrid, and accessibility scenarios.
- Execute tests across Chromium, Firefox, and WebKit.
- Run tests through GitHub Actions.
- Generate reports, traces, screenshots, and videos for debugging.

## Test Scope

The final suite will contain **20 formal automated test cases**.

| Test Layer | Number | Coverage |
| --- | ---: | --- |
| UI | 10 | Registration, authentication, upload, products, search, cart, checkout, and invoice |
| API | 7 | Positive and negative requests, search, authentication, and account CRUD |
| Hybrid API + UI | 1 | API setup, UI verification, and API cleanup |
| Accessibility | 2 | Axe scans on the home and products pages |
| **Total** | **20** | Multi-layer automated coverage |
